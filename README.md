# 💬 카카오톡 답장 어시스턴트 (Personal KakaoTalk Reply Assistant)

Claude AI 기반의 개인용 카카오톡 답장 생성 · 번역 데스크탑 앱 (Electron)

---

## 🚀 빠른 시작

### 1. 사전 요구사항
- [Node.js](https://nodejs.org/) v18 이상 (LTS 권장)
- [Claude API 키](https://console.anthropic.com/) (Anthropic Console에서 발급)

### 2. 설치 및 실행

```bash
# 선택한 폴더로 이동
cd kakao-reply-assistant

# 패키지 설치
npm install

# 앱 실행
npm start
```

### 3. API 키 설정
앱 실행 후 좌측 하단 ⚙️ 버튼 → API 키 입력 → 저장

### 4. 설치 파일 배포 (Windows EXE / macOS DMG)

```bash
# 설치 파일 빌드 도구 설치
pnpm install

# Windows 설치 파일(.exe) 생성
pnpm dist:win

# macOS 설치 파일(.dmg) 생성
pnpm dist:mac
```

- 결과물은 `dist/` 폴더에 생성됩니다.
- Windows: `*.exe` (NSIS 설치 파일)
- macOS: `*.dmg`

GitHub에서 다운로드 가능하게 배포하려면:
1. `v1.0.1` 같은 태그를 푸시합니다.
2. GitHub Actions(`.github/workflows/release.yml`)가 Windows/macOS 빌드를 수행합니다.
3. 생성된 `.exe`/`.dmg`가 GitHub Releases에 자동 업로드됩니다.

참고:
- 로컬에서 macOS DMG 빌드는 개발 환경 상태(권한/디스크 유틸리티 설정)에 따라 실패할 수 있습니다.
- 실제 사용자 배포용은 GitHub Actions의 `windows-latest`, `macos-latest` 러너에서 생성하는 방식을 권장합니다.
- macOS에서 경고 없이 배포하려면 Apple 코드 서명/노타리제이션 설정이 추가로 필요합니다.

## 📋 주요 기능 (MVP 1)

| 기능 | 설명 |
|---|---|
| **채팅방 관리** | 대화 상대별 채팅방 생성/삭제 |
| **상대방 프로필** | 성별, MBTI, 성격, 관계 유형, 언어 설정 |
| **답장 추천** | AI가 3~5개의 다양한 톤 답장 생성 |
| **답장+번역** | 영어/일본어/중국어로 답장 생성 |
| **단순 번역** | 텍스트 양방향 번역 + 역번역 확인 |
| **금기 표현** | 상대가 싫어하는 표현 필터링 |
| **입력 방식 유연성** | 채팅 텍스트를 직접 복사/붙여넣기하거나 내보내기 파일 내용으로 넣어도, 입력된 맥락에 맞춰 답변 생성 |

| 성별 | 필수 | 남성/여성/미지정 |

| 내 언어 | 필수 | Korean (기본) |
| 상대 언어 | 필수 | Korean/English/Japanese/Chinese |
| 금기 표현 | 선택 | AI가 해당 표현 생성 금지 |

## 🏷️ 답장 라벨 종류

- **안정형** — 안전하고 무난한 답장
- **다정형** — 감정적으로 따뜻한 답장
- **장난형** — 유머/가벼운 장난기 포함
- **단호형** — 명확하고 직접적인 답장
- **짧게** — 간결하고 짧은 답장

## 🔒 보안 / 정책

- API 키는 로컬 기기에만 저장, 외부 전송 없음
- 상대방 프로필은 사용자 직접 입력 (AI 추정 없음)
- 민감 주제(폭력/자해/불법) 필터 적용
- 개인 식별/추적 기능 없음
